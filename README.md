# 小征 · 本地个人助手

图片转动态角色的 agent 工具箱已整理为独立子项目：[cz-img2live2d](packages/cz-img2live2d/README.md)。它连接 PuppetLoom 的绑定精调、Anime2.5DRig 的补件和长征的排练能力，帮助 agent 从分层素材构建、检查并继续修改角色；当前为实验版。

直播画面与动作调试使用[离线模拟器](simulator/README.md)：运行 `启动模拟器.ps1`，访问 <http://127.0.0.1:17874/sim>。仓库包含最新排练副本、模型和三段测试语音。

Live2D 后续制作先读 [制作与调校复用笔记](docs/LIVE2D-REUSE.md)：当前资产、重建入口、动作经验、失败路线与视觉验收方法。

可运行的 Windows 桌宠原型。双击 **启动小征.cmd**（或 start.cmd）。本机依赖与加密模型凭据已配置，无需重新填 Key。浏览器备用入口：<http://127.0.0.1:17861>。

这是参考 N.E.K.O.、Neuro SDK、LiveKit 行为做的独立小应用，没有导入 N.E.K.O. 运行时，也没有宣称复现 Neuro 的内部系统。

最新 Live2D 独立预览已运行在 <http://127.0.0.1:17869/>（默认日和与本地慧慧音色，测试数据独立，自动记忆关闭）。对应直播画面为 <http://127.0.0.1:17869/stage>。私人桌宠用半身取景，直播保留全身；直播画面中途刷新会恢复当前已播字幕与嘴型。日常 17861 实例尚未重启；关闭后再次正常启动才会加载全部新后端功能。

## 现在可以做什么

- 动画小猫、内置 Live2D 日和，支持换成 GIF / APNG / PNG / WebP。形象下方可直接切换；Live2D 根据当前播放音频音量开合嘴，打断立即闭嘴。右上角箭头切成可调整大小的置顶桌宠窗口。
- 输入文字或开启麦克风。快速对话默认 Qwen3.5-35B-A3B，CosyVoice2 说话、SenseVoiceSmall 识别；计算服务在云端，本机保存界面、会话和记忆。
- **Esc / 停止 / 开始说话**打断。浏览器立即停音，后端取消生成；本地Windows音色支持词边界播放进度，云端音色按完整短段确认。未播出的草稿不进入下一次模型输入。
- Codex app-server 在独立任务会话里读文件、执行工具。聊天停止与后台任务暂停分开；任务页可以暂停/继续，工具许可会在界面出现。完成或失败后，在私人场景空闲时主动简短汇报；主人输入时不抢话，直播时不播私人任务结果。
- 自动整理明确事实和偏好，或点消息旁「记住」。SQLite持久化提取队列，进程重启会接着整理，失败有限重试；记忆页显示进度并支持重试。语义与关键词召回区分场景/私人公开；同义事实尝试归并，明确改口尝试更新旧偏好，来源可查看、修改、忘记。
- 直播预览有弹幕测试入口：最多100条候选，15秒过期，最近8个不同话题合成一次输入，播放期间的新弹幕不打断当前话，不积压逐条回复。拥挤时发言最多28字，低流量48字，达到上限主动关闭模型流。
- OBS 浏览器来源：<http://127.0.0.1:17861/overlay>，透明画面，只在直播场景显示已确认播放的字幕，不重复播放声音。音频由 OBS 捕获桌面版音频。
- 直播姬准备：完整背景画面 <http://127.0.0.1:17861/stage>；本机软件检查与尚待完成的导入/音轨验收见 [直播姬接入说明](docs/BILIBILI.md)。没有对外开播。

## 打断和恢复的准确含义

设置里可选本机已安装的 Windows 音色，例如 Microsoft Huihui Desktop。它提供引擎词边界时间戳；浏览器用估计的设备输出时钟上报进度，打断时只保留已越过词末边界的前缀。数字等不可分单元不强行拆字，不按总时长均分文本。

CosyVoice2云端音色没有提供该对齐数据，因此仍按不超过约18字符的完整段确认；打断段整体舍弃，可能少记已听到的几个字。两种路径都不会把网络首包或生成完成当成已播放；这也不是物理扬声器/真人听感的精确测量。

打断后说「继续」，助手根据已说内容和最新输入重新组织回答。后台 Codex 任务通过同一 thread 恢复；这不是任意外部动作的事务回滚/精确一次执行，继续前会让 Codex 核对实际状态。

## 记忆与本机数据

数据目录：`%LOCALAPPDATA%\Changzheng`。

- `companion.db`：对话、场景记忆、语义索引、任务和设置。
- `provider.key`：当前 Windows 用户绑定的 DPAPI 加密凭据，API 不回传密钥。
- `avatars/`：自选形象；`server*.log`：本地服务日志。

记忆删除是**从召回/模型上下文中忘记**，不是磁盘取证级抹除。原消息/来源审计可能仍在数据库中，但会被排除；更正/删除同时保守地排除旧助手对话。生成期间发生更正时，旧上下文产生的后续已播内容保留审计，但不会重新进入下一轮历史。

语义合并和改口判断只比较同场景、同可见性的最近30条候选；自动更正需要明确原话证据，并检查候选版本和来源时间。模型曾在实测中漏合并同义事实，失败记录已保留，不能承诺任意说法都正确消解；记忆页仍可手动修正。关闭自动记忆会暂停在途提取、保留待办。

关闭桌宠窗口后，本机后台继续运行，Codex 任务可以继续；再次双击会重新连接。麦克风默认关闭，窗口关闭后音频输入停止。

## 新电脑安装

需要 Python 3.11+、Node.js 22.12+，以及已经登录的 `codex.exe`。项目目录执行：

```powershell
npm.cmd ci
.\start.cmd
```

首次启动会创建 `.venv` 并安装锁定的 Python 依赖。如果没有 Electron，启动器打开浏览器版；在设置中填写自己的 SiliconFlow Key。可用进程环境变量 `SILICONFLOW_API_KEY` 覆盖本机凭据，`CHANGZHENG_DATA_DIR` 指定隔离数据目录。

## 验证

`python -m pytest tests -q` 覆盖播放账本、实际下一次模型输入、记忆重启/更正/删除、语义缓存、直播拥塞以及 Codex 暂停竞争。开发测试另需 pytest；浏览器探针需 Playwright，接口探针需 requests/websockets。

真实接口与浏览器报告见 [验收记录](docs/ACCEPTANCE.md)。`probes/` 中的网络脚本会消费真实模型请求，测试服务使用17862及隔离数据，不能直接对日常数据库做清理测试。

尚未接入真实直播平台弹幕/推流、Live2D Cubism 模型和真人麦克风回声环境。当前交付优先覆盖本地可用链路，OBS 预览和弹幕调度已经可测试。
