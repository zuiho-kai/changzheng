# 小征 · 本地个人助手

可运行的 Windows 桌宠原型。双击 **启动小征.cmd**（或 start.cmd）。本机依赖与加密模型凭据已配置，无需重新填 Key。浏览器备用入口：<http://127.0.0.1:17861>。

这是参考 N.E.K.O.、Neuro SDK、LiveKit 行为做的独立小应用，没有导入 N.E.K.O. 运行时，也没有宣称复现 Neuro 的内部系统。

## 现在可以做什么

- 动画小猫，支持换成 GIF / APNG / PNG / WebP。右上角箭头切成可调整大小的置顶桌宠窗口。
- 输入文字或开启麦克风。快速对话默认 Qwen3.5-35B-A3B，CosyVoice2 说话、SenseVoiceSmall 识别；计算服务在云端，本机保存界面、会话和记忆。
- **Esc / 停止 / 开始说话**打断。浏览器立即停音，后端取消生成，只把完整播放确认过的短句写入对话；未播出的草稿不进入下一次模型输入。
- Codex app-server 在独立任务会话里读文件、执行工具。聊天停止与后台任务暂停分开；任务页可以暂停/继续，工具许可会在界面出现。
- 自动整理明确事实和偏好，或点消息旁「记住」。SQLite 持久化，语义与关键词召回，区分陪伴/工作/直播及私人/公开；记忆页可看来源、修改、忘记。
- 直播预览有弹幕测试入口：最多100条候选，15秒过期，最近8个不同话题合成一次输入，播放期间的新弹幕不打断当前话，不积压逐条回复。
- OBS 浏览器来源：<http://127.0.0.1:17861/overlay>，透明画面，只在直播场景显示已确认播放的字幕，不重复播放声音。音频由 OBS 捕获桌面版音频。

## 打断和恢复的准确含义

语音输出被切为不超过约18个字符的短段，客户端自然播放结束才确认。中途停止的那一段整体舍弃，因此可能漏记其中已经听到的几个字，但不会把尚未说出的后半句冒充已说。**当前没有逐字音频对齐**；仅网络音频首包或文本生成完成都不算「用户听到了」。

打断后说「继续」，助手根据已说内容和最新输入重新组织回答。后台 Codex 任务通过同一 thread 恢复；这不是任意外部动作的事务回滚/精确一次执行，继续前会让 Codex 核对实际状态。

## 记忆与本机数据

数据目录：`%LOCALAPPDATA%\Changzheng`。

- `companion.db`：对话、场景记忆、语义索引、任务和设置。
- `provider.key`：当前 Windows 用户绑定的 DPAPI 加密凭据，API 不回传密钥。
- `avatars/`：自选形象；`server*.log`：本地服务日志。

记忆删除是**从召回/模型上下文中忘记**，不是磁盘取证级抹除。原消息/来源审计可能仍在数据库中，但会被排除；更正/删除同时保守地排除旧助手对话，避免它重复旧事实。现有语义阈值只经小样例校准，复杂矛盾消解和大规模记忆质量仍需更多实际对话验证。

关闭桌宠窗口后，本机后台继续运行，Codex 任务可以继续；再次双击会重新连接。麦克风默认关闭，窗口关闭后音频输入停止。

## 新电脑安装

需要 Python 3.11+、Node.js，以及已经登录的 `codex.exe`。项目目录执行：

```powershell
npm.cmd ci
.\start.cmd
```

首次启动会创建 `.venv` 并安装锁定的 Python 依赖。如果没有 Electron，启动器打开浏览器版；在设置中填写自己的 SiliconFlow Key。可用进程环境变量 `SILICONFLOW_API_KEY` 覆盖本机凭据，`CHANGZHENG_DATA_DIR` 指定隔离数据目录。

## 验证

`python -m pytest tests -q` 覆盖播放账本、实际下一次模型输入、记忆重启/更正/删除、语义缓存、直播拥塞以及 Codex 暂停竞争。开发测试另需 pytest；浏览器探针需 Playwright，接口探针需 requests/websockets。

真实接口与浏览器报告见 [验收记录](docs/ACCEPTANCE.md)。`probes/` 中的网络脚本会消费真实模型请求，测试服务使用17862及隔离数据，不能直接对日常数据库做清理测试。

尚未接入真实直播平台弹幕/推流、Live2D Cubism 模型和真人麦克风回声环境。当前交付优先覆盖本地可用链路，OBS 预览和弹幕调度已经可测试。
