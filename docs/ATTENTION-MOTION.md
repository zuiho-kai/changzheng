# 视线与上身动作 · 2026-09-06

用户连续反馈“动作呆”“待机也活泼”“仍不像 Neuro 活人”，本轮从增加跳动频率转为补视线和输入反应。视觉参考沿用已核实的2026年录播，见 `artifacts/neuro-2026/source.json`。

当前模型的眼睛原先只能开闭、笑眼和惊讶，没有瞳孔方向。新增 `ParamEyeBallX/Y`，虹膜区域变形保持眼角与外侧眼皮不动；注视短暂离开镜头后收回。视线先变化，约160ms后头部开始跟随，身体随后。新弹幕通过 stage → overlay/broadcast → Live2D 的现有父子页面传递触发看向弹幕和轻抬眉；说话时不抢走视线，开始说话会看回镜头。

上身起落现在从腰部向肩颈渐变，脸和脖子一起移动；整模型平移降至 `.018`，保留小跳、偶发连跳与侧倾停顿。没有添加侧脸投影或肩臂独立关节。

初稿把视线烘焙为眼部组合关键形态，使模型从7.2MB增至32.3MB。最终改为运行时局部虹膜顶点变形，模型为7,229,504字节。Cubism更新前恢复原生顶点，更新后再施加视线，固定姿势连续200次更新无累计漂移。此视线依赖 `web/avatar-performance.js`，单独复制MOC到其他播放器不会获得该表现。

验证：

- `probes/attention_review.py`：左右上下、闭眼、实际眼部顶点变化，固定姿势漂移0，页面无错误。截图与结果在 `artifacts/attention-review/`。
- `probes/attention_live.py`：实际17870 `/stage` 观察页录制。前10秒自然待机，随后只在此测试页模拟一条弹幕状态更新，走真实前端视线反应链；未向后台或B站发送测试弹幕，未注入音频。全程嘴巴闭合，视线范围达到约-0.53至0.85，未报页面错误。
- 软件渲染加录屏平均约19.8fps，不能当作正常GPU窗口帧率。当前Codex实际预览DOM读数29.6fps，目标上限30fps。
- 七项动作检查和三项语音交付测试通过。真实播音窗口已重开、当前预览已加载，播音连接与AudioContext运行正常。

结果录像：`artifacts/attention-review/live.mp4`。这改善了注视和反应，尚不具备Neuro完整肩臂动作与模型表演细节。
