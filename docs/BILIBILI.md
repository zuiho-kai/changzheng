# 直播姬接入准备

本机已安装并成功打开哔哩哔哩直播姬 **7.64.0.10819**，启动入口 `G:\livehime\livehime.exe`。当前账号已登录，界面停在「开始直播」之前。没有对外开播。

已观察到素材/H5插件入口；安装包中有 `obs-browser.dll` 与 `win-capture-audio.dll`。这证明具备浏览器及音频采集组件，尚不等于完成实际素材导入验收。

## 已准备的画面

- 完整1920×1080背景与桌宠：[直播画面](http://127.0.0.1:17861/stage)
- 叠加在游戏上的透明桌宠：[透明画面](http://127.0.0.1:17861/overlay)
- 桌面控制：[小征](http://127.0.0.1:17861/)

直播姬里新建一个小征专用场景，添加浏览器/H5网页素材，填入上述一个画面地址，尺寸1920×1080。网页只接收公开直播场景的已播字幕，不显示私人聊天、记忆或任务内容。

画面网页本身不重复播音；声音从小征桌面进程输出。优先在直播姬选择应用音频采集并指定小征，避免同时采集同一声音两次。当前直播姬已有桌面音频来源；正式联调时需要核实混音选择和实际录制音轨，而不能只看音量条。

小征切到「直播预览」，现有弹幕测试入口可验证候选合并、过期丢弃和短回复。尚未连接真实B站弹幕，不能把该入口当成真实观众接入。
