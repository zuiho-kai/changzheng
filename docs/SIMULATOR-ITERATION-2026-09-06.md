# 模拟器中的直播动作迭代

## 当前模拟器版本：agent-v2

子代理将看弹幕调整为「眼神先行、头跟随、身体落位、停读、依次回到观众」，并取消开口时强制点头。真实音频的停顿划分动作段落，同一句内保留有方向的强调；平静陪伴使用较轻的肩部动作。

主代理复核后追加：好奇的固定歪头只在开头出现，随后逐渐回正，让说话的动作接替；句末退回待机使用平滑过渡。保持此前撤销的头部/上身缩放为零。当前录像与报告在 `artifacts/runtime-simulator/iterations/agent-v2/`，旧版对比文件不代表当前版本。

完整手臂手势仍未加入；当前改进集中在动作顺序和语音停顿的对应关系。

## 用户复核后的修正

用户指出第二轮右侧出现突然的大头动画。原因是「靠近」通过放大头部及上身的网格实现，产生了不需要的缩放感。已在模拟器撤掉这项缩放，保留肩部动作、状态区分和表情时长调整。以下两轮记录描述的是历史候选；当前修正版录像与报告位于 `artifacts/runtime-simulator/iterations/v3-no-zoom/`。

本轮仅修改 `simulator/workspace/avatar-performance.js` 和 `simulator/workspace/app.js`。
未修改直播使用的 `web/`，没有请求直播端口或重启直播进程。

## 改动

待机保留小跳、探头、歪头与错开的肩部动作。倾听先看向弹幕，再靠近并停留；思考略微后收、偏头并抬起一侧肩部。说话时由真实音频的强调点带动头、身体和肩部，平静回应使用较轻的动作。

肩部与靠近动作直接作用于模拟器中现有模型的顶点。面部各贴片使用相同的上身变换，每次更新前恢复原生顶点，避免累积形变。没有生成或更换角色立绘，也没有新增完整的手臂骨骼。

表情从原先的 1.35–2.3 秒超时改为贯穿短句，播放结束后短暂保留再归位；打断立即清理。开心时保留与观众的眼神接触，笑意出现时短暂闭眼。

## 两轮验收

第一轮实现不同状态的姿态和肩部参与。回看完整直播构图后，肩部变化仍偏弱，因此第二轮提高局部肩部幅度与说话强调动作，保留平静回应的安静姿态。

两轮均通过同一个模拟器脚本，使用相同的三段 Diana 录音，依次运行待机、模拟弹幕、倾听、思考、说话、打断和陪伴。第二轮实测：

- 四个状态均到达；两段自然播完，一段中途打断。
- 真实音频嘴型峰值约 0.88，结束后归零。
- 测试观察页无 JavaScript 错误，也没有离开模拟器来源的 HTTP 请求。
- 保持同一姿态连续更新 200 次，模型顶点无累积漂移。
- 另外检查了完整场景逐秒画面、倾听连续动作序列和倾听/思考/耸肩的近景。

录像均为静音画面。声音由当前打开的模拟器播音页面实际播放；测试不包含在线 LLM 或 TTS。
