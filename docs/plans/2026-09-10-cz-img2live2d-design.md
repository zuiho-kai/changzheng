# cz-img2live2d 设计草案

状态：用户已确认聚合长征、PuppetLoom、Anime2.5DRig 三方能力并授权实施。原始草案下述接口由实施计划细化。

## 用户确认后的调整

核心是聚合三方已经打磨的能力。长征保留素材补图、正面表情 MOC3、语音状态驱动及排练经验；PuppetLoom 接入原生 CLI 的 PSD 制作、精调、修订、动作与导出；Anime2.5DRig 接入原始自动绑定和浏览器运行时。统一项目记录各后端产物和来源，不假设三家的网格、坐标和运行时格式可以无损互换。优先保留原生能力的可调用性，再逐步提供便利命令。

## 定位

长征旗下、纯供外部 agent 使用的图片转 Live2D 制作工具。用户给 agent 一张角色图，agent 使用自己的看图和图像编辑能力，调用本项目完成素材整理、绑定、导出、预览和返修，交付可驱动的模型、可重建来源与实际效果证据。

首版放在 `packages/cz-img2live2d/`，可独立安装和运行；长征只是首个消费方。包不导入长征对话服务、直播接收器或凭据。需要提取的低层依赖必须记录来源和版本，不能运行时偷读父项目 `.reference/`。

## 路线选择

1. 推荐：agent Skill + Python CLI + 文件项目。智能判断交给调用方 agent，稳定的几何处理、构建、渲染和结果记录交给工具。适合 Codex 等已有文件、图像工具的 agent，也便于失败后局部返修。
2. 直接包装小征构建脚本：最快复现小征，但写死角色坐标和素材，不能兑现通用图片输入。
3. 独立托管生成服务/MCP 平台：增加模型接入、任务调度和部署工作，首版不采用。需要时可在稳定 CLI 外增加适配。

## 一条制作流程

原画 → agent 分析部件和缺失素材 → agent 拆层/补图 → 同画布 PNG 图层与绑定说明 → 构建原生 Live2D 包 → 固定取景排练 → agent 查看证据并返修 → 导出。

没有分层或闭眼/张嘴素材时，返回明确的 `needs_assets` 状态及所缺文件、区域、要求；agent 用已有图像工具完成后续步骤。单张图起步是整条 agent 工作流的能力，不能把“只收分层 PNG 的构建器”宣传成自动完成单图转换。

## 首版接口草案

```text
cz-img2live2d init --image character.png --project work/character
cz-img2live2d inspect --project work/character
cz-img2live2d build --project work/character
cz-img2live2d review --project work/character
cz-img2live2d export --project work/character --out output/character
```

命令无交互提示，stdout 返回 JSON，日志写 stderr。结果包含状态、产物路径、问题与下一步；失败返回非零退出码。每次构建保留独立 revision，失败不覆盖上次可用结果。首版仅实现这条实际制作路径，不先做通用任务平台。

Skill 说明从原图到交付的具体操作顺序、补图约束、何时查看图像、如何修改绑定和如何恢复中断的工作。它不绑定某家图片 API，也不在包内增加 agent 对话循环。

## 输入与输出

项目文件保存原图、画布尺寸、图层路径与绘制顺序、五官/头颈/肩等锚点、局部作用区域及参数范围。所有坐标明确使用原图左上角为原点、Y 向下；与模型坐标的转换集中处理。

输出包含：

- `model/`：实际 `.moc3`、`.model3.json`、贴图和实际引用的表情/动作文件。
- `source/`：用于重建的图层、绑定配置与依赖版本记录。
- `review/`：约 30 秒连续录像、关键姿态截图、机器检查报告和 agent 视觉复核结论。
- `capabilities.json`：逐项说明模型支持的动作与已验证环境。

网页运行时特有的状态、语音驱动如需交付，单独提供驱动文件和协议；仅拿走模型文件不能承诺复现长征全部表演。首版不承诺 `.cmo3` 编辑工程或未实测的 VTube Studio 兼容性。

## 复用范围

从 `probes/build_expression_rig.py` 提取网格、关键形态和 MOC3 输出经验，把写死的尺寸、补片区域、锚点改为角色配置。现有脚本仍保留为历史基准，不直接覆写。

从模拟器中的已修复版本提取必要的表演与验收经验；源码需逐项核对。PuppetLoom、Anime2.5DRig 的分层绑定可作为后续实现参考，其 README 声明不构成本项目原生 Live2D 输出能力的证据。

首个可用范围是清晰正面角色的眨眼、嘴型、眉眼表情、侧倾、点头、身体跟随和有限头发摆动。左右大角度侧脸和完整手臂结构需要对应素材及绑定，不能用整图缩放或随机拉伸补足。

## 验收与首个交付

1. 用小征已对齐素材完成可重建包，并与现有角色做相同取景对照。
2. 换第二张不同角色图片，从原图完整走 agent 素材准备流程；构建器不再为此修改 Python 坐标常量。没有第二个角色实测，标注通用性未验收。
3. 连续排练包括待机、表情、模拟弹幕反应、已有语音及中途打断。检查身份和画风、面部漂移/放大、接缝、口型与动作自然度。可加载与几何检查通过，分别记录，不代替视觉结论。
4. 长征接入候选只进入 `simulator/workspace/` 独立目录，在 `http://127.0.0.1:17874/sim` 刷新排练版本。实验网页和模型副本均位于模拟器工作区，候选切换保留现有排练模型。
5. 首版不访问 17870、真实弹幕或直播窗口，不发布到 `web/`。后续发布遵循用户单独指令。

本次只完成代码与任务调研及设计草案，尚未创建包、迁移实现或运行新转换流程。
